## 尺寸（与文档一致）

| 项目 | 值 |
|:--|:--|
| 灯体 / 法兰 | Ø3.0 × 5.0 / Ø4.0 × 0.5 |
| 灯脚 | Ø0.5，两脚间距 **2.54**，总长 25–27 |
| 层内间距 / 层距 | 20 mm / 20 mm |
| 夹具板 | 150 × 150 × 2，孔 Ø3.0（图上按 Ø3.8 画，两脚都在孔内） |
| 阳极弯折长度 | **21.5 mm**（20 mm 到隔壁灯 + 1.5 mm 搭接） |
| 阴极竖直段 | 22 mm（每层比层距多 2 mm 叠焊） |

## 关键几何（建模时发现的坑）

**两只灯脚必须垂直于弯折方向错开**：

- 阳极沿 **+x** 弯折 → 两脚要沿 **y** 错开（阳极 −y、阴极 +y）；
- 如果两脚也沿 x 排（长脚左、短脚右），弯过去的阳极会在 2.54 mm 处**压在隔壁阴极脚上短路**；
- 错开后阳极母线走 `y−1.27` 这条线、阴极在 `y+1.27`，永不相交。

同理，纵向跨接线要走在**两列灯之间**（x = 10 / 90），不能走在灯列上（x = 20 / 80）。

## 重新生成

```bash
# 3D 模型 + 渲染（用办公环境里的 Python，自带 numpy/matplotlib）
python scripts/cad_led_cube.py
python scripts/cad_solder_diagram.py
```
