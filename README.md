# 6 × 6 × 6 蓝光 LED 光立方（ESP32 标准版）

216 只 F3 蓝光灯、100 mm 见方的立方体，由一块 **ESP32 DevKit V1（标准版）** 驱动，
每只灯有 16 级独立亮度。

> **范围说明**
> 本项目包含：**光立方本体**、**驱动板（原理图 + PCB，立创EDA 已画完）**、**固件**、**CAD/工艺卡**。
> 驱动板：100×100 mm、2 层、四角 M3，顶面只有 42 个通孔焊盘、器件全部贴底面；
> 详见 `HANDOFF.md` 第 2 节。

## 30 秒看懂原理

1. **每层 6×6 = 36 只灯**，6 层摞起来。
2. **竖直方向 6 只灯共用一根列线（阴极）** → 全立方体共 36 根列线。
3. **水平方向 36 只灯共用一条层线（阳极）** → 共 6 条层线。
4. 任意一只灯由 `(列 x,y, 层 z)` 唯一确定，所以 **36 + 6 = 42 路** 就能控制 216 只灯。
5. 任一时刻只给 **一层** 阳极加电，然后在这 36 根列线上送这一层要亮的图案；6 层轮流，每秒轮 202 次，人眼就看成同时亮。
6. **每只灯还能有 16 级亮度**：每一层内部再切成 8:4:2:1 的 4 个子场，某个子场只点亮“该位为 1”的灯，人眼积分后就是 0–15 级灰度。

> 因为每只灯只有 1/6 的时间通电，可以用比静态更高的峰值电流（20–30 mA），平均亮度仍然够。
> 灰度完全靠软件时序，**接线、芯片、驱动电路都不变**。

## 制作路线

```
买灯(240只) → 逐只测亮 → 做 20mm 夹具 → 焊 6 层(每层 36 只)
    → 每层单独测试 → 用 20mm 垫块逐层摞起来焊阴极柱
    → 引出 6 根层线 + 36 根列线 → 接驱动板 → 烧固件 → 用自检模式逐点核对
```

预计工时：**焊灯 6–9 小时**，测试与排故 2–3 小时，合计 **10–12 小时**。

## 快速上手（做好之后）

```bash
cd firmware
pio run                 # 编译
pio run -t upload       # 烧录（USB 线接 ESP32）
pio device monitor -b 115200
```

串口命令：

| 键 | 功能 |
|:--|:--|
| `1`~`7` | 切换 7 个动画（含一个专门看灰度的径向渐变） |
| `n` | 下一个动画 |
| `t` | **逐点自检**（装好后第一件事，216 点约 26 秒） |
| `d` | 灰度阶梯：直接数出 16 级亮度 |
| `s` | 全亮测试 |
| `h` | 帮助 |

## 两点提醒

1. **74HCT595，不是 74HC595**。ESP32 是 3.3 V 逻辑，74HC 系列在 5 V 供电时高电平门限是 3.5 V，会识别不可靠；74HCT 的门限是 2.0 V。
2. **本机 PlatformIO 的 xtensa 工具链缺少 `cc1plus.exe`**（`pio run` 会报 `cannot execute 'cc1plus'`），
   这是工具链包被清理导致的环境问题，与固件无关。可在装了 ESP32 开发板的 Arduino IDE 里编译，
   或重装 PlatformIO 的 `toolchain-xtensa-esp32` 包后再编译。
